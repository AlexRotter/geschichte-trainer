# Geschichte-Trainer (Klasse 6)

Interaktive Lern-App zu den Heftseiten: Woher unser Wissen über Geschichte stammt, Geschichtliche Quellen,
Epochen und Zeitleiste, Leben und Wohnen in der Altsteinzeit. Mit Erklärfragen (selbst prüfen), Probearbeit und Lernstand.

`index.html` ist komplett eigenständig und kann auch als einzelne Datei weitergegeben werden. Lernstand nur lokal im Browser.
